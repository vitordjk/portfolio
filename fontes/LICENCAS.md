# Fontes auto-hospedadas

Nenhuma requisição externa. Os dois arquivos abaixo são servidos pelo próprio
GitHub Pages, a partir desta pasta.

## archivo-var-latin.woff2

Archivo, de Omnibus-Type. Variável no eixo de peso, de 400 a 900.
Subconjunto latin (U+0000 a U+00FF e pontuação), 34 KB.
Licença SIL Open Font License 1.1.
Origem: https://fonts.google.com/specimen/Archivo

## jetbrains-mono-var-latin.woff2

JetBrains Mono, de JetBrains. Variável no eixo de peso, de 400 a 700.
Subconjunto latin, 31 KB.
Licença Apache License 2.0.
Origem: https://fonts.google.com/specimen/JetBrains+Mono

Ambas as licenças permitem uso, incorporação e redistribuição em site.
Ao atualizar um arquivo, manter o mesmo nome para não quebrar o preload
declarado no index.html.
